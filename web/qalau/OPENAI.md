# QALAU — интерфейс подбора

Запуск: `uv run uvicorn app:app --port 8012`.
Интерфейс: http://127.0.0.1:8012/. Документация: `/docs-ui`, схема API: `/docs`.
Предыдущий интерфейс доступен по `/legacy`, отчёт проверок — `/tests` и `/api/tests`.

`api.mjs` загружает каталог из `/api/meta`, примеры из `/api/demo` и отправляет условия в `/api/match`.
Кандидатов, порядок, факты и причины определяет сервер. Готовые объяснения приходят от языковой модели или шаблона.
Для автоматического запуска примера добавьте `?example=1` (номера 1–6 или имя сценария из API).

Три иллюстрации категорий в assets/generated созданы с помощью image_gen; это не реальные портфолио подрядчиков.
Блоки кода в документации не выполняют вставленный код. Шрифты поставляются локально с лицензиями OFL.
