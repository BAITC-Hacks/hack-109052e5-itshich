Подбор подрядчиков

От условий мероприятия — к трём подходящим вариантам. Устройство локального подбора, параметры и примеры кода.

Движок отбирает свободных подрядчиков по городу, категории, бюджету и формату события. Одинаковый запрос возвращает одинаковый порядок: сначала по начальной цене, затем по идентификатору.

Локальный прототип

Примеры используют функции проекта. HTTP API и авторизация не реализованы. Датасет подключается отдельно и не публикуется в репозитории.

Быстрый старт#

Создайте модуль в корне проекта. Импортируйте каталог и передайте условия в selectProfiles(data, query).

Для импорта catalog.mjs нужен локальный source-data.mjs. Путь импорта зависит от расположения вашего файла.

Проверить подбор в интерактивном примере →

Параметры запроса#

Денежные значения передаются числами в тенге. Названия города, категории и формата должны совпадать со значениями каталога.

ПараметрТипОписание
citystringОбязательный. Город мероприятия.
categorystringОбязательный. Категория подрядчика.
datestringОбязательный. Дата в формате YYYY-MM-DD.
formatstringОбязательный. Например, «Свадьба».
budgetnumberОбязательный. Верхняя граница начальной цены.
languagestringЯзык работы. Пустая строка снимает ограничение.
hoursnumberДлительность. Ноль снимает ограничение.

Движок ожидает подготовленные значения. Проверяйте корректность даты и чисел до вызова функции.

Результат подбора#

items содержит до трёх профилей; total — число всех подходящих, а pool — число профилей выбранной категории в городе.

Условный пример: в городе есть два профиля категории, оба заняты. Это иллюстрация структуры, а не ответ из датасета.

Счётчики reasons показывают причины исключения. Один профиль может не пройти несколько условий, поэтому сумма счётчиков может превышать pool.

Состояния выдачи#

success
Найден хотя бы один вариант. Покажите рекомендации и объяснения.
absent
В городе нет выбранной категории. Предложите изменить город или услугу.
filtered
Категория есть, но никто не прошёл условия. Используйте реальные счётчики причин.
Цена «от» — ориентир

Попадание в бюджет по начальной цене не гарантирует итоговую стоимость. Сохраняйте эту оговорку рядом с рекомендациями.

Форматирование кода#

Вставьте фрагмент, выберите язык и посмотрите оформление. JSON можно автоматически выровнять. JavaScript подсвечивается с сохранением ваших отступов. Код не выполняется.

JSON будет отформатирован с отступом в два пробела.
