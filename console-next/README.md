# Подбор подрядчиков — Небо

Светлый прототип с белым фоном, акцентами #6482F2 и #D2EAFF, новым хедером и футером.

Три шага: выбор услуги, условия мероприятия, до трёх рекомендаций с объяснениями. Поиск и группы услуг, сохранение условий, состояния ошибок и пустой выдачи. Переключателя палитр нет.

Запуск из корня репозитория после локального импорта данных по инструкции основного README:

```sh
python -m http.server 5173 --bind 127.0.0.1
```

Откройте http://127.0.0.1:5173/console-next/?palette=sky (или /console-next/sky.html). Палитра фиксирована, параметр palette не нужен. Пример с результатами: /console-next/?example=1.

Датасет не входит в репозиторий. Используется локальный source-data.mjs, исключённый из Git. Без него подбор не работает. Общие catalog.mjs, engine.mjs и локальные OFL-шрифты уже находятся в корне проекта.
