# QALAU — OpenAI-прототип

Тёмный прототип подбора подрядчиков: /console-next/openai.html.
Документация в той же палитре: /console-next/openai-docs.html.

Из корня репозитория запустите `python -m http.server 5173 --bind 127.0.0.1`.
Откройте http://127.0.0.1:5173/console-next/openai.html.
Для готового примера добавьте ?example=1.

Подбор требует локальный source-data.mjs. Импорт CSV описан в основном README. Датасет не публикуется и исключён из Git. Документация и форматирование фрагментов работают без датасета.

Три иллюстрации категорий в assets/generated созданы с помощью image_gen; это не реальные портфолио подрядчиков. Блоки кода не выполняют вставленный код. Шрифты поставляются локально с лицензиями OFL.
