# Собрано — UI/UX-прототип

Русскоязычный адаптивный интерфейс подбора event-подрядчиков. До трёх рекомендаций с объяснениями, фильтры мероприятия, состояния загрузки, ошибок и пустой выдачи.

## Локальный запуск

Датасет не включён в репозиторий. Получите CSV отдельно и подготовьте локальный каталог (Python 3):

```sh
python import-data.py "путь/к/датасету.csv"
python -m http.server 5173 --bind 127.0.0.1
```

Откройте http://127.0.0.1:5173/. Без локального каталога подбор не запустится. На компьютере, где каталог уже подключён, повторный импорт не нужен.

`source-data.mjs` создаётся только локально и исключён из Git. Не публикуйте этот файл. Установка зависимостей и сборка не требуются; открывать HTML нужно через HTTP-сервер, не file://.

## Состав

- `index.html`, `style.css` — интерфейс.
- `app.mjs` — взаимодействия и карточки.
- `catalog.mjs`, `engine.mjs` — обработка локальных данных и подбор.
- `import-data.py` — локальный импорт отдельно предоставленного CSV.
- `fonts/` — шрифт Manrope и лицензия OFL.

Прототип использует локальные правила подбора, без LLM, бронирования, платежей или отправки заявок. Цена «от» не является итоговой сметой.

## Прототип 2 — «Консоль»

Тёмный интерфейс в каталоге `console/`: параметры события, до трёх кандидатов, сравнение и объяснения. После локального импорта CSV откройте http://127.0.0.1:5173/console/. Готовый пример: http://127.0.0.1:5173/console/?example=1.

В эту версию включён только вариант «Консоль». Другие дизайн-концепции не публикуются. Шрифты Source Serif 4 и IBM Plex Sans поставляются локально вместе с лицензиями SIL OFL. Датасет по-прежнему не входит в репозиторий.
