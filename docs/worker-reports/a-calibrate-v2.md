## Что сделано

- `data/calibration/v1/`: побайтовые копии трёх исходных файлов v1; оригиналы также оставлены без изменений.
- `data/calibration/v2/requests.json`: прежние 16 запросов, прежний split 10/6 по семействам,
  заново рассчитанные 68 строк признаков, сырые и анонимизированные факты, текущие приоры,
  зафиксированный протокол, параметры SDK, якоря и хеши происхождения.
- `data/calibration/v2/judgments.jsonl`: 98 сырых ответов, записи попыток и проверенные рейтинги.
- `data/calibration/v2/result.json`: все 125 loss, выбранные множители, `weights_by_group`,
  отдельная рекомендуемая таблица, метрики, consistency, все голоса/метки/веса, консенсус и хеши входов.
- `scripts/calibrate_weights.py`: CLI v2 и итоговая оценка; отдельные модули
  `calibration_data.py`, `calibration_protocol.py`, `calibration_journal.py`,
  `calibration_metrics.py`, `calibration_fit.py`. Самый большой — 124 строки.
- `tests/test_calibrate.py`, `tests/test_calibrate_journal.py`: офлайн-проверки агрегирования,
  soft labels, двух видов consistency, циклов большинства, train-only fit, API-параметров,
  полноты рейтинга, backoff, concurrency, глобального лимита и восстановления журнала.
- В [исследование](../research/calibration.md#раунд-2) добавлен раздел «Раунд 2» с таблицами и решением.

Все признаки получены через текущий `score_all()` с производственным `EmbeddingScorer`.
Семантика пересчитана по якорям P05=0.22155170065111932, P95=0.506944405362618,
32058 пар каталога. Изменились все 68 semantic scores; остальные признаки, факты,
eligible-кандидаты, даты, бюджеты и split совпадают с v1. Новых векторов и вызовов embedding API — 0.
Приоры точно воспроизводят текущие production scores, в том числе при незапрошенных часах.

Судья: `gpt-5.4-2026-03-05`, `reasoning_effort="medium"`, `seed=42`,
`max_completion_tokens=1500`, strict JSON Schema через `chat.completions.create`.
Поддержка всех параметров проверена через сигнатуру установленного SDK.
Каждый запрос получил 3 разных seeded-присвоения меток K1..Kn × 2 порядка показа.
В payload нет ID, имён, scores или split; собственные имена внутри описаний скрыты.
Рейтинг строгий и полный, confidence 1–5 для каждой позиции. Промпт и split после начала судейства не менялись.

Всего **96 завершённых заданий за 98 попыток**; ошибок API — 0.
В q09/assignment=1/forward и q12/assignment=2/reverse ответы обрезаны на 1500 токенах;
оба сырых ответа сохранены, повтор с теми же параметрами успешен. Все 98 snapshot совпали с запрошенным.
Расход: 142457 входных + 78008 выходных = **220465 токенов**.
Concurrency ≤4, максимум 149 попыток на эксперимент, бюджет попыток сохраняется после рестарта.

Для soft labels намеренно исполнено буквальное правило задачи: при 4:2 метка
`y=0.83/0.17`, вес 0.5; эмпирическая доля 4/6 или 2/6 хранится отдельно.
Pairwise agreement сравнивает направление большинства, macro по запросам;
pair weights участвуют в BT, дополнительная взвешенная accuracy также сохранена.
Kendall сравнивает порядок ранкера с точным Kemeny-консенсусом шести голосов.

## Открытые вопросы

- Для следующего эксперимента нужны новые семейства запросов: held-out здесь прежний,
  поэтому повторная проверка не считается независимым новым тестом и не доказывает клиентскую точность.
- У 6 запросов по два оптимальных порядка консенсуса из-за пар 3:3; циклов большинства нет.
  Эти пары требуют человеческого разбора. Нужна также человеческая проверка соответствия rubric ожиданиям заказчика.
- no_presence/decor не представлен; общая рекомендация этой группы сохраняет prior, а не отдельно обученную оценку.
- Бюджет 1500 включает reasoning: это вызвало два повтора. Параметры завершённого эксперимента
  зафиксированы; при новом протоколе можно отдельно исследовать больший лимит без изменения этого журнала.
- `RTK.md`, упомянутый во внешнем AGENTS.md, отсутствует в worktree и проверенных родительских каталогах.
